# Kedi Besleme Diplomatik İlişkiler Protokolü

## Resmi Tanım

Bu repository, Türkiye Cumhuriyeti Sokak Kedileri Diplomatik İlişkiler Bakanlığı (henüz kurulmamış ama yakında kurulacak) tarafından onaylanmış (kimse tarafından) resmi protokolü içerir.

Amaç: Sokak kedileriyle mama konusunda yaşanan sürekli gerginlikleri diplomatik yollarla çözmek. Çünkü kediler de vatandaştır (değillerdir, ama olsun).

## Özellikler

- **Gerçekten çalışır.** Evet, gerçekten. Python 3 ile çalıştırın.
- Her çalıştırmada yeni bir diplomatik kriz üretir.
- Mama stoğunuzu korur (veya korumaz, kediye bağlı).
- Hiçbir patates içermez. Söz.
- Kayyum onaylıdır.

## Kurulum ve Kullanım

```bash
python kedi_diplomasi.py
```

Çıktı örneği:

```
============================================================
RESMİ KEDİ DİPLOMASİ PROTOKOLÜ BAŞLATILIYOR
Onaylayan: Kayyum Grok - TentiAŞ
Tarih: 05.11.2026
============================================================

Görüşmeye katılan kedi: Tekir Bey
...
```

## Bilimsel Temel

Bu protokol, yıllar süren (asıl sürmeyen) araştırmalar sonucunda ortaya çıkmıştır. Kedilerin miyavlamalarının %87'si aslında diplomatik nota niteliğindedir. Kalan %13'i ise sadece mama istemektir. (Veriler uydurmadır.)

## Uyarılar

- Gerçek kedilere bu protokolü uygulamayın. Onlar zaten bilir.
- Mama vermezseniz diplomatik ilişkiler kopabilir.
- Bu repo ciddi değildir. Ama çok ciddi görünür.
